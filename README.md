# Arielkap Homebrew Tap

Official Homebrew Tap for CoreDeck and macOS developer utilities by Armako Limited.

## Installation

Install CoreDeck via Homebrew Cask:

```bash
brew install --cask Arielkap/tap/coredeck
```

Or add the tap first:

```bash
brew tap Arielkap/tap
brew install --cask coredeck
```

## Available Casks

| Cask | Description | Version |
| :--- | :--- | :--- |
| [`coredeck`](Casks/coredeck.rb) | Apple Silicon HUD & remote Linux/VPS telemetry companion | `2.0.0` |
